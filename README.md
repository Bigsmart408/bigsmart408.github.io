# Bifangqi's Homepage

Personal academic homepage for Fangqi Bi.

Website: [https://bigsmart408.github.io](https://bigsmart408.github.io)

## Local Preview

Serve the repository with any static HTTP server. For example:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Content

- `contents/config.yml`: site title and footer settings
- `contents/home.md`: biography, education, and research interests
- `contents/awards.md`: awards
- `contents/experience.md`: experience
- `contents/publications.md`: publications
- `static/assets/img/`: profile and background images
